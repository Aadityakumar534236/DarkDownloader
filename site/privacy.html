PRIVACY

Your data stays yours.

Local storage

DarkDownloader stores preferences and queue URLs in local browser storage so queued work can be submitted later. History records only the source hostname for new entries. Clear queue and history when no longer needed. Browser storage is not synchronized across devices and can be lost when site data is cleared.

Server requests

When you analyze a URL or submit a queue job, the URL is sent to the configured DarkDownloader server for provider matching. Do not submit private or signed URLs. The initial application has no account system or database.

Security

The server validates public HTTP and HTTPS addresses and blocks local and private network destinations. Hosted environments may impose additional networking limits. Never use the service to access content or systems without authorization.
