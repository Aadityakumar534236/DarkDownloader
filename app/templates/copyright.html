Use media responsibly.

Only process content you own, have permission to download, or are otherwise legally entitled to obtain. Provider terms, copyright rules, and exceptions vary by place and source; this page is general product guidance, not legal advice.

Provider restrictions

DarkDownloader does not bypass DRM, access controls, authentication, paywalls, or provider restrictions. YouTube downloading is not implemented. An API that returns metadata does not authorize media downloading.

Report a concern

For a project issue, use the repository’s issue tracker if one is available. Do not include private URLs, access tokens, or other secrets in a report.
